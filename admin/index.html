Расписание «239+»

Здесь меняются окна записи на сайте. Изменения появляются на сайте через 1–2 минуты после «Сохранить».

Ключ GitHub

Хранится только в этом браузере. Никому его не пересылайте.

Где взять ключ
  1. github.com → аватар → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Resource owner: 239plus. Repository access: Only select repositories → 239plus.github.io.
  3. Permissions → Repository permissions → Contents: Read and write. Срок — например, 1 год.
  4. Generate → скопировать ключ и вставить сюда.
Репетитор:

Постоянные окна по неделе

Нажмите на час, чтобы открыть или закрыть его каждую неделю. Зелёный — открыто.

Ближайшие 2 недели

Нажмите на открытое окно, чтобы отметить его занятым (или снова свободным). Серые — закрыты в шаблоне.
