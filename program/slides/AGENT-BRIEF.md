Требования к содержанию:
- Язык — русский, обращение к ученику на «вы» в слайдах; конспект («say») — к репетитору.
- ~15–18 слайдов на 60 минут (сумма min ≈ 55–60): титул → разминка → теория → 3–4 разобранных примера (steps) →
  6–8 задач ученику (ans) → (задача с полным решением, если уместно) → итог → слайд «Домашнее задание».
- Поле say у каждого слайда: что говорить, наводящие вопросы, подсказки, типичные ошибки. Подсказки и мысли
  репетитора — ТОЛЬКО в say, не в b/steps (презентацию видит ученик).
- hw: 6–8 задач с ответами [[условие, ответ], ...]. goal, why, need — как в образце.
- Задачи ПРИДУМЫВАЙ САМ по типам из работ 239 — не копируй условия из архива 239 дословно (можно сослаться:
  «задача 9 из работы 2025 года» в say). Уровень — как в рейтинговой работе 239 для этого класса, не выше.
- Занятия «Пробник №…» / «Финальный пробник»: презентация — короткая (правила, тайминг, как оформлять, потом
  слайды разбора типичных ошибок по темам варианта своими задачами-аналогами); say — как проводить пробник и
  разбирать; ссылка на работу архива (https://cdn.sch239.net/site/pages/admission/archive/<файл из GRADES[g].archive>).
  hw — 5–6 задач-аналогов на повторение.
- Вводная диагностика — аналогично: план диагностики + свои короткие задачи по разным темам.
- Математика через KaTeX: $...$ внутри строк JS, обратный слэш удваивать (\\dfrac, \\cdot). Никакого HTML кроме
  <ol>/<ul>/<li>/<b>/<p>/<div class='box'>/&nbsp;. Для геометрии — словесные условия (без картинок).
